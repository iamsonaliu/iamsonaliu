## 🚀 Projects That Matter

### 🍽️ [Fullstack Restaurant Application](https://github.com/iamsonaliu/Fullstack_restaurant_Application)
A complete restaurant web app — browse menu, place orders, and manage the backend.
Built with **React + Node.js + PHP + MySQL**.

> *End-to-end: real frontend, real backend, real data. Not a template.*

---

### ⚙️ [Mini-C Compiler — Frontend Visualizer](https://github.com/iamsonaliu/mini-C-compiler-frontend-visualisation)
An interactive compiler front-end that performs **lexical analysis**, **syntax parsing**, and **semantic checks** — with a live D3.js parse tree rendered in the browser.
Built with **Python (PLY/Flask) + React + D3.js**.

> *Theory meets practice: compiler design you can actually see and interact with.*

---

### 🗺️ [Campus Navigation System](https://github.com/iamsonaliu/Campus_Navigation)
A graph-based navigation system for navigating within a campus — shortest path finding applied to a real-world layout.
Built with **Python / JavaScript**.

> *DSA applied to a problem students actually face every day.*

---

### 🚨 [Emergency Traffic Corridor System](https://github.com/iamsonaliu/Emergency-Traffic-Corridor-System)
A system that dynamically clears traffic corridors for emergency vehicles using smart signal logic.
Built with **Python / C++**.

> *Systems thinking applied to public safety — because some problems actually matter.*
